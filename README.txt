SITE SAFETY INSPECTION: HOW TO RUN
1. Host: drag this whole folder onto https://app.netlify.com/drop (or GitHub Pages). You get a https link.
2. QR per team: make 3 QR codes for  <link>/index.html?team=A , ?team=B , ?team=C
3. Instructor: open <link>/index.html?key=trainer  -> shows Score / Reveal answers.
4. AR: the "View on my table" button works on most Android (Chrome) and iPhone (Safari). If it fails, the 3D view still works.
5. Fallback: print printables/pen_and_paper_pack.pdf (team sheet + site plan), one per team; answers in answer_key_and_scoring.pdf.
Scoring: +10 hazard, +5 correct type, -5 false flag.
